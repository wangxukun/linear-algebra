# 任务 1.1 · 向量的本质（理论讲义）

> Stage 1 · 第 1 讲 | 2026-09-25 | 流程：理论先行 → 自检题批改 → 代码可视化

## 0. 这节课要解决的问题

"向量"这个词你可能背过定义："既有大小又有方向的量"。没错，但那只是起点。本讲的目标是建立三个层次的认识：

1. 向量是**数字的有序列表**（计算机眼中的它）；
2. 向量是**空间中的箭头/位移**（几何学家眼中的它）；
3. 这两个身份**说的是同一个东西**——线性代数的全部威力，都来自在两个视角之间自由切换。

## 1. 从标量到向量：两种身份

**标量（scalar）**：单独一个数。温度 25°C、电阻 100 Ω——只有大小。

**向量（vector）**：

- **代数身份**：一组**有序**的数字列表。v = (3, 4)，三维的 v = (2, −1, 5)，竖起来写就是列向量 [2, −1, 5]ᵀ。每个数字叫一个**分量**，列表长度叫**维数**。"有序"很关键：(3, 4) ≠ (4, 3)。
- **几何身份**：一支**箭头**——有长度、有方向。以原点为尾、以点 (3, 4) 为头的箭头，和数字列表 (3, 4) 是**同一个对象**。

**位置向量 vs 自由向量**：从原点出发画的叫**位置向量**，此时"向量"与"空间中的点"互相指代（点 (3,4) ↔ 向量 (3,4)），放心混用。严格说向量不拴在原点——平移后长度方向不变就还是同一个**自由向量**；但线性代数里默认都从原点画。

## 2. 模长：箭头有多长

记号 ‖v‖（也写 |v|）。

**二维推导**（公式为什么长这样）：v = (v₁, v₂)。从原点走到 (v₁, v₂)，水平走 v₁、竖直走 v₂，恰好是一个直角三角形的两条直角边，勾股定理：

    ‖v‖² = v₁² + v₂²    ⟹    ‖v‖ = √(v₁² + v₂²)

**三维**：勾股定理用两次。v = (v₁, v₂, v₃)：它在地面上的投影 (v₁, v₂, 0) 长度为 d = √(v₁² + v₂²)；再从投影点竖直爬升 v₃，又是一个直角三角形：

    ‖v‖² = d² + v₃² = v₁² + v₂² + v₃²

n 维同理（数学归纳可得）：‖v‖ = √(v₁² + v₂² + ⋯ + vₙ²)。

**例**：‖(3, 4)‖ = √(9+16) = 5；‖(2, 3, 6)‖ = √(4+9+36) = √49 = 7。

**重要性质**：‖k·v‖ = |k|·‖v‖（数乘按 |k| 缩放长度，第 5 节回收）。

**EE 钩子**：一段离散信号 (x₁, x₂, …, xₙ) 本质就是 n 维向量，‖x‖ 正是"信号总强度"的推广（与 RMS 幅值只差因子 √n）。

## 3. 方向：把箭头归一化

方向不是数，但可以用一个**模长为 1 的向量**表示——**单位向量**：

    v̂ = v / ‖v‖      （满足 ‖v̂‖ = 1）

于是任何向量都能拆成"长度 × 方向"：

    v = ‖v‖ · v̂

**例**：v = (3, 4)：‖v‖ = 5，v̂ = (3/5, 4/5) = (0.6, 0.8)。验证：0.6² + 0.8² = 1 ✓。

这个操作叫**归一化**，工程里无处不在（比较两个向量的方向是否一致时，先各自归一化）。

**特例警报**：v = **0** 时 v̂ = v/‖v‖ 没有定义——**零向量没有方向**。这不是数学洁癖，Stage 1.4 判线性相关时它是关键角色。

## 4. 向量加法：两次位移的合成

**几何法则一 · 三角形法则（首尾相接）**：u + v = "先沿 u 走一遍，再从 u 的头沿 v 走一遍"的净位移——从 u 的尾直指 v 的头。

```
        C ●
         / ˙
      v /    ˙    u+v = A→C
       /       ˙
      /          ˙
   A ● ————————→ ● B
          u
```

**几何法则二 · 平行四边形法则**：u、v 从同一起点画出，补成平行四边形，对角线就是 u+v。把 v 平移到 u 的头上（自由向量允许平移），它就退化成三角形法则——两个法则天然一致。

```
      C ●────────● D
       /        /
    v /      u /          对角线 A→D = u+v
     /        /
  A ●───────→ B
        u
```

**代数法则**：对应分量相加：

    u + v = (u₁+v₁,  u₂+v₂,  u₃+v₃)

**为什么代数与几何必然一致**（本讲第一个 aha，务必吃透）：u = (3, 1) 的本义就是位移"向东 3 步、向北 1 步"。先做 u 再做 v = (−1, 2)：总共向东 3 + (−1) = 2 步、向北 1 + 2 = 3 步——恰好 (2, 3)，正是分量相加的结果。**"分量相加"不是人为规定，而是"位移首尾相接"的必然记账方式。**

**交换律 u+v = v+u**：代数上显然；几何上就是平行四边形的两条邻边——对角线只有一条。

**例**：u = (3, 1)，v = (−1, 2) ⟹ u + v = (2, 3)。

**EE 钩子**：两个同频交流电压叠加，用相量（phasor）表示后就是两个平面向量做加法；KVL"回路电压相量和为零"画在相量图上，就是一条首尾相接后**恰好回到原点**的封闭多边形——三角形法则的电路版。

## 5. 数乘：缩放与翻转

**代数法则**：k·v = (k·v₁, k·v₂, k·v₃)。

**几何意义**（k 分情况）：

- k > 1 拉长；0 < k < 1 缩短——方向不变；
- k < 0：**反向**，再缩放 |k| 倍；
- k = 0：塌缩成零向量 **0**（一个点）。

**关键观察**：所有 k·v 都落在**过原点的同一条直线**上（k>0 在 v 同侧，k<0 在对侧）。"数乘出直线"——这是 Stage 1.3 张成空间、1.4 线性相关的种子，先埋在这儿。

```
            2v ↗
         v ↗            k > 0：同一条射线上伸缩
      ½v ↗
   ●————————————————————→
   ↞ -v                  k < 0：翻到反向射线
   O（原点）
```

**减法不需要新定义**：u − w = u + (−1)·w。

**互补运算**：v + (−1)·v = **0** ——负向量是位移的"撤销键"。

**性质回收**：‖k·v‖ = |k|·‖v‖——现在能看出为什么取绝对值：k < 0 时方向翻但长度只看 |k|。

## 6. 零向量：唯一没有方向的向量

**0** = (0, 0, 0)，‖**0**‖ = 0，方向不存在，是唯一"只是一个点"的向量。

- 加法单位元：v + **0** = v；
- 数乘吸收态：k·**0** = **0**，0·v = **0**。

**伏笔**：将来判断"一组向量是否线性相关"，本质就是问"能否用非平凡系数把它们组合成 **0**"。从今天起留意零向量的特殊性。

## 7. 一页小结

| 概念 | 代数（计算机视角） | 几何（空间视角） |
|---|---|---|
| 向量 v | 有序数字列表 (v₁,…,vₙ) | 从原点出发的箭头 |
| 模长 ‖v‖ | √(v₁²+⋯+vₙ²) | 箭头长度 |
| 方向 v̂ | v/‖v‖（模长归一） | 箭头指向 |
| 加法 u+v | 分量对应相加 | 首尾相接 / 平行四边形对角线 |
| 数乘 k·v | 分量同乘 k | 沿过原点的直线伸缩，k<0 反向 |
| 零向量 **0** | 全 0 列表 | 原点上的一个点，无方向 |

**EE 速记**：离散信号 = n 维向量；信号叠加 = 向量加法；增益 = 数乘；信号强度 = 模长；相量 = 平面向量。
